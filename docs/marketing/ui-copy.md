| Where | Text |
|---|---|

| Check-in button (sending) | sending signal… |
| Check-in success card | your check-in is in. Scrap felt that — see you tomorrow. |
| Check-in already-done card | you've already checked in today. Scrap remembers. |
| Helper line under the score picker | anonymous, once a day. any score powers him; only silence doesn't. |
| Check-in error line | your check-in did not go through — try again. |
| Power caption: asleep | Scrap is asleep. no signal in the last 24 hours. the first check-in wakes him. |

| Log header | overnight log · {weekday}, {Mon D} |
